# Dota 2 Market Parser

Веб-приложение для поиска предметов Dota 2 на [Market.Dota2.net](https://market.dota2.net/) по названию, качеству и содержимому описания.

## Возможности

- Поиск предметов по названию.
- Фильтрация по качеству:
  - Normal
  - Exalted
  - Inscribed
  - Autographed
  - Heroic
  - Corrupted
- Поиск предметов по тексту описания.
- Определение призматических самоцветов по описанию предмета.
- Отдельный режим поиска предметов с самоцветами.
- Фильтрация найденных предметов по конкретному самоцвету без повторного запроса к API.
- Поддержка известных самоцветов и автоматическое обнаружение неизвестных.
- Отображение цены, количества предложений, описания и ссылки на предмет на Market.
- Отображение прогресса поиска в реальном времени.

### 2. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 4. API-ключ

Для работы приложения необходим API-ключ Market.Dota2.net.

Ключ можно получить здесь:

[https://market.dota2.net/docs-v2](https://market.dota2.net/docs-v2)

Создайте файл `.env` в корне проекта:

```env
MARKET_API_KEY=ваш_api_ключ
```


## Как работает поиск

1. По названию предмета выполняется поиск через Market API.
2. Для выбранных качеств собираются найденные варианты.
3. Дубликаты удаляются по `classid + instanceid`.
4. Информация о предметах загружается через `MassInfo`.
5. Из описаний извлекается текст.
6. Выполняется поиск по заданному описанию или определяются призматические самоцветы.
7. Результаты отображаются в интерфейсе.

Для режима самоцветов все найденные предметы обрабатываются один раз. После этого можно переключаться между самоцветами локально, без повторного обращения к Market API.

## Важные файлы

**`market_api.py`**
Работа с API Market.Dota2.net и получение информации о предметах.

**`search_service.py`**
Основная логика поиска, обработки предметов, определения самоцветов и формирования результатов.

**`description_parser.py`**
Преобразование HTML-описаний предметов в обычный текст и поиск по описанию.

**`app.js`**
Логика интерфейса, потоковое отображение прогресса, результаты поиска и локальная фильтрация по самоцветам.

## Ограничения

Приложение зависит от доступности API Market.Dota2.net и корректности предоставляемых им данных.

Для работы приложения требуется действующий API-ключ.
